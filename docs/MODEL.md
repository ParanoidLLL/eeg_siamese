# 模型与质量机制

每个5秒窗口有62电极、1250个采样点。每电极按0.5秒切成10片，每片125个数经线性层变为64维token，加上可学习电极编码和窗口内正弦时间编码。一次时间轴attention让同电极的时间片交互，再做一次电极轴attention。当前深度为1组，4头，输出128维单位向量；无CNN前端、无窗口间attention，也未加入头皮几何坐标。

硬掩码来自NaN、平线、跳变/断点和滤波保护区。一个片段内含无效采样即屏蔽该token；输入置零、禁止作为信息源、清除无效输出并排除聚合。未提供ADC范围时不猜测饱和界限，不做坏道插值。

软质量q采用固定幅值代理：q = 1 / [1 + (片段去均值RMS / 100微伏)^2 + (相邻差分RMS / 20微伏)^2]；硬失效取0。attention logits加log(q)，池化也按q加权。q不是可学习质量概率或真实SNR，高幅有效EEG也可能被降权。

同一片段训练时随机生成受污染视图：概率0.8、通道遮挡比例上限约20%、平滑噪声和短暂接触丢失，污染选择不读取身份标签。原始和污染视图共用编码器，两者均有梯度。目标为跨日SupCon加0.5权重的平均一减余弦一致性；温度0.1，辅助分类权重0。测试不加人工污染。

每6窗产生一个片段向量，片段按质量总量聚合成记录向量。同身份的注册记录先分别归一化，再取归一化均值形成模板，查询取余弦最高身份。该规则不等于片段多数投票。

默认训练35轮、每轮100步、4身份乘2样本/批，学习率0.0003、weight decay 0.001、seed42。早停仅用于源身份独立开发，eval_every=5、early_stopping_evaluations=3；有最终查询时不得将它充当开发集。无开发集的最终源训练使用固定35轮。

EncoderConfig中少量旧字段仅用于解析既有轴向检查点元数据，不存在其他模型分支。网络设计采用沿不同轴分别计算注意力的思路，原始概念见[Axial Attention in Multidimensional Transformers](https://arxiv.org/abs/1912.12180)；当前EEG系统是任务适配，不是该论文实验的复现。
